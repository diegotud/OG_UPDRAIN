# OG_UPDRAIN

**OG_UPDRAIN** (**O**pen-access **G**IS-based **U**rban **P**luvial and **DRAIN**age evaluation tool)

Interactive tool for urban pluvial flood risk assessment and evaluation of mitigation measures.
Full description and instruction manual coming soon...
Three version available:

1. LID version: for the automatic implementation of LIDs into hydrodynamic model.
2. Recession version: includes implementation of GebreEgziabher et al., 2020 (https://www.mdpi.com/2073-4441/12/4/1160) for manhole recession
3. FLood barrier: for interactive creation of temporary flood barriers

Check out our other tool: 
https://github.com/diegotud/OG_FLUSH/ 
The outputs of OG_FLUSH are automatically prepared for OG_UPDRAIN
